# GTA6 Voice

Веб-прототип для Android: камера телефона считывает **уже русские** субтитры с экрана и произносит их через системный голосовой движок телефона.

## Запуск
Открой GitHub Pages сайта в Chrome на Android, разреши доступ к камере и нажми «Включить камеру». Подключённая к телефону Bluetooth-колонка тоже подойдёт: звук выводит сам Android.

## Возможности прототипа 0.1
- OCR на русском и английском с помощью Tesseract.js.
- Чтение нижней части изображения, где обычно выводятся субтитры.
- Двукратное совпадение текста перед озвучкой для снижения случайных срабатываний.
- Системная русская озвучка Android.
- Отдельный выбор доступных голосов по умолчанию, для Jason и для Lucia.
- Ручная проверка голоса и регулировка скорости и громкости.

## Ограничения
- Это ранний прототип, а не готовый релиз.
- Реальная задержка зависит от телефона, качества изображения, бликов, размера субтитров и скорости OCR. Значение меньше секунды пока не подтверждено.
- Голоса для персонажей зависят от установленных в Android голосовых движков. Если русский голос один, разные персонажи будут звучать одинаково.
- Если имя говорящего не попадает в ту же область изображения или распознаётся неверно, реплика будет озвучена голосом по умолчанию.
- Tesseract.js и языковые данные загружаются из сети. На первом запуске загрузка может занять время.
- Если камера смотрит на проектор, постарайся убрать блики, сфокусировать изображение и держать камеру неподвижно.
