# GTA6 Voice

Браузерное приложение для Android: камера телефона считывает русские субтитры с экрана и произносит их через системный голосовой движок телефона.

## Запуск

Открой GitHub Pages в Chrome на Android, разреши доступ к камере и нажми «Включить камеру». Bluetooth-колонка тоже подойдёт: звук выводит сам Android.

## Текущая технология

- **PaddleOCR.js 0.4.2 + PP-OCRv5** с поддержкой русского языка.
- Распознавание работает в отдельном Web Worker через ONNX Runtime Web (WASM), чтобы не блокировать интерфейс.
- При первом запуске браузер загружает модель и необходимые runtime-файлы. Дальше браузер может использовать свой HTTP-кэш.
- Из кадра берётся только пользовательская область ROI; найденные строки сортируются по координатам сверху вниз.
- Две строки субтитров собираются в правильном порядке и передаются в очередь Android Speech Synthesis.

## Возможности

- Камера и перемещаемая/изменяемая рамка области распознавания.
- Независимое включение распознавания и озвучки.
- Русские голоса Android, отдельные настройки для Jason и Lucia, скорость и громкость.
- Ручная проверка голоса.
- Диагностический вывод распознанных строк и времени OCR.

## Разработка

Приложение собирается Vite и публикуется GitHub Actions в GitHub Pages.

```bash
npm install
npm run build
```

Параметр `base` в `vite.config.js` настроен для репозитория GitHub Pages `/Gta6Voice/`.

## Ограничения

- Точность и скорость зависят от камеры, фокуса, масштаба субтитров, бликов и мощности телефона.
- PaddleOCR не гарантирует безошибочное чтение каждого кадра. Нужно проверять на реальных игровых сценах.
- Распознавание выполняется на устройстве; интернет нужен для первой загрузки SDK, WASM runtime и моделей.
- Системный голос зависит от установленных в Android голосовых движков.
